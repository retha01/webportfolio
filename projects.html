Gym Equipment Guide (React Native)

View on GitHub ↗
  • React Native
  • Expo
  • JavaScript

The problem

Many people walk into a gym without knowing how to use certain equipment, which muscles or body parts it targets, or which workouts go best with it.

Why these languages

React Native with Expo lets me build one JavaScript codebase that runs on both iOS and Android, and test it quickly on a real phone. This was my first React Native project, and I wanted the practice to go towards solving a real problem.

How it solves it

The app gives people a quick way to look up a piece of equipment and see how it’s used, what it targets and which workouts pair well with it.

Pet Booking System

View on GitHub ↗
  • C#
  • ASP.NET Core
  • SQL Server
  • React
  • JWT

The problem

Pet owners and pet-care providers often arrange bookings through scattered phone calls and messages, which leads to double bookings and no single record. They need one secure place to create an account and manage bookings.

Why these languages

C# with ASP.NET Core gives a fast, strongly typed API with built-in support for JWT authentication. SQL Server suits the related data (users, pets, bookings) and enforces rules such as unique emails. React keeps the sign-in, sign-up and signed-in views simple to build.

How it solves it

Users sign up and log in through a React front end. The C# API hashes passwords with bcrypt, checks them against SQL Server and returns a short-lived JWT. Protected endpoints accept only requests with a valid token, which is the base the booking features are being built on.

Timeless Travels (University of Pretoria capstone)

View on GitHub ↗
  • C#
  • ASP.NET Core
  • SQL Server
  • Azure
  • Angular

The problem

Travellers need one place to browse, book and manage trips, and the business needs reliable booking data behind it.

Why these languages

ASP.NET Core and C# for a structured REST API, SQL Server for a relational booking database (later moved to Azure SQL), and Angular for a responsive single-page front end.

How it solves it

The app lets users book trips through a web front end backed by REST APIs and a normalised database. It also includes an AI chatbot using machine-learning APIs, and the team deployed it through a GitHub Actions pipeline.
