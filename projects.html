Pet Booking System

View on GitHub ↗
  • C#
  • ASP.NET Core
  • SQL Server
  • React
  • JWT

The problem

Pet owners and pet-care providers often arrange bookings through scattered phone calls and messages, which leads to double bookings and no single record. They need one secure place where owners can create an account and manage their bookings.

Why these languages

C# with ASP.NET Core gives a fast, strongly typed API with built-in support for JWT authentication. SQL Server suits the data well, because users, pets and bookings are related and need rules such as unique emails. React keeps the interface simple to build, with the sign-in, sign-up and signed-in views driven by one piece of state.

How it solves it

Users sign up and log in through a React front end. The C# API hashes passwords with bcrypt, checks them against SQL Server, and returns a short-lived JWT. Protected endpoints accept only requests with a valid token, which is the base the booking features are being built on.
